📊 **LogAnalyzer - System Log Monitoring Tool**

📌 Description
I developed LogAnalyzer as a Python-based tool to analyze system log files and detect suspicious activities. This project focuses on identifying anomalies, failed login attempts, and unusual patterns in logs. The goal is to automate log monitoring and improve security analysis.

🚀 Features
I can read and analyze log files 📂
I can detect suspicious patterns using regex 🔍
I can identify failed login attempts 🚫
I generate structured output reports 📊
Simple CLI-based interface

🛠️ Technologies Used
Python
File Handling
Regular Expressions (Regex)
JSON/CSV (for report generation)

📂 Project Structure
LogAnalyzer/
│── log_analyzer.py # Main program
│── sample.log # Input log file
│── report.json # Output report

⚙️ Installation & Setup
Install Python from official website

(No external libraries required)

▶️ How to Run

I run the program

The tool scans and analyzes logs
